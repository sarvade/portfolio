## What was at stake

Analysts and data scientists in one region needed creator and seller data that lives under another region's data-residency rules. In that setting, one protected column crossing the boundary isn't a bug. It is a compliance incident. And I couldn't query the source directly to check my own work the usual way.

## The call

<Callout label="The call">
  No table is the easy one. Every table gets the same pattern, so correctness comes from the process instead of from remembering which tables were risky.
</Callout>

**Substitute, don't drop.** Protected fields keep their column and type and lose their value. Dropping columns would have broken downstream schemas silently, three hops away from anything I could see. The shape of it, as an illustrative pattern rather than production code:

```sql
-- Protected fields keep their column and type, lose their value
select item_id,
       content_category,                         -- approved for transfer
       play_cnt,                                 -- approved for transfer
       cast(null as bigint) as protected_metric, -- substituted, not dropped
       dt
from   source_daily
where  dt = '{{ ds }}';
```

**Validate rows, not job status.** A completed transfer job proves the job ran, not that the data is right. I validated row by row across the two regions. I also resolved a partition field named differently on each side, a mismatch that would have quietly produced empty results.

**Own the old ones too.** When a compliance review flagged a row-level identifier on an older transfer that predated my work, I remediated it within the SLA using the same pattern instead of debating whose it was.

## Result

Zero compliance findings across every table I transferred. I built a self-serve dataset so analysts stopped filing ad-hoc requests, and investigation turnaround went from about three days to about an hour. I wrote the reference (SQL, schemas, partitions and compliance notes for each table), and it became the team's standard for later transfers. The part I'm proudest of is that it works without me in the room.
